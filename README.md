# awilonk.github.io

Personal homepage of Yaokun Lu (卢耀坤), Ph.D. student at Beihang University.

Built with Jekyll on GitHub Pages. Template from [keunhong.github.io](https://github.com/keunhong/keunhong.github.io),
adapted from [jiajindou.github.io](https://github.com/JIAjindou/jiajindou.github.io), licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

## Where to edit

| What | File |
|---|---|
| Intro paragraph, email, GitHub, ORCID | `_config.yml` |
| News | `_data/news.yml` |
| Publications (thumbnails in `images/pubs/`) | `_data/publications.yml`, co-authors in `_data/authors.yml` |
| Talks and awards on the home page | `_data/talks.yml` |
| CV page: education / experience / awards | `_data/education.yml`, `_data/appointments.yml`, `_data/employment.yml` |
| Platform photos (transparent PNG) | `images/hardware/`, cards in `index.html` |
